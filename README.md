# Deep Learning Coursework

A curated collection of coursework projects completed as part of a **Deep Learning** course at the **University at Buffalo**. These assignments were cleaned, reorganized, and documented for portfolio presentation on GitHub.

## Included Projects

### Assignment 00 - Neural Network Foundations
Topics covered:
- neural network implementation and experimentation
- model training and evaluation
- deep learning workflows in PyTorch
- report-based analysis and saved model artifacts

### Assignment 01 - Sequence Modeling with LSTMs
Topics covered:
- time-series forecasting with stacked LSTMs
- sequence generation and temporal modeling
- hyperparameter tuning across learning rate and batch size
- early stopping and evaluation with MAE, RMSE, and R²
- sentiment analysis with baseline and improved LSTM architectures
- bidirectional LSTMs, attention mechanism, layer normalization, and dropout regularization

### Assignment 02 - Deep Learning Applications
Topics covered:
- autoencoder-based anomaly detection
- Transformer implementation from scratch for text classification
- positional encoding, self-attention, multi-head attention, and encoder blocks
- fine-tuning BART for abstractive summarization
- evaluation with ROUGE, BLEU, and BERTScore
- bonus work in linear probing for spam classification and multi-dataset summarization

## Tech Stack
Python, PyTorch, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, Hugging Face Transformers, NLTK, Jupyter Notebook
