# Deep Learning Coursework

A curated collection of coursework projects completed as part of a **Deep Learning** course at the **University at Buffalo**. These assignments were cleaned, reorganized, and documented for portfolio presentation on GitHub.

## Included Projects

### Assignment 00 - Neural Network Foundations
Topics covered:
- neural network implementation and experimentation
- model training and evaluation
- deep learning workflows in PyTorch
- report-based analysis and saved model artifacts

## Tech Stack
Python, PyTorch, NumPy, Pandas, Matplotlib, Jupyter Notebook
